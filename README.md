## 📖 نبذة عن المشروع / Overview

تطبيق علمي تفاعلي ثلاثي الأبعاد (WebGL) يحاكي **القبة الفلكية وحركة الأجرام ومواقيت الصلاة** بدقة هندسية ورياضية فائقة، مستنداً إلى النماذج الفلكية لعالم الفلك الدمشقي **علاء الدين علي بن إبراهيم بن الشاطر الأنصاري (704 - 777 هـ / 1304 - 1375 م)** موقّت الجامع الأموي الكبير بدمشق، وكتابه المرجعي *"نهاية السول في تصحيح الأصول"*.

يقدم التطبيق محاكاة بصرية كاملة لحركة الشمس اليومية والسنوية، تغير الفصول، أثر ميل المدارات مع خط عرض الراصد، وحساب مواقيت الصلاة عبر قواعد الربع المجيب الفلكية وانحطاط الشمس تحت الأفق لزاويتي العشاء الشافعي (16°) والحنفي (18°).

## ✨ المميزات الرئيسية / Key Features

1. **🌐 قبة فلكية تفاعلية ثلاثية الأبعاد (Interactive 3D Sphere):**
   - استعراض كامل بزاوية 360° مع التقريب والإزاحة والتحكم الحر أو التدوير التلقائي.
   - إظهار خط الاستواء السماوي، فلك البروج، مدار السرطان، ومدار الجدي، وقرص الأفق المحلي مع اتجاه القبلة المشرفة.
   - مجسمات متحركة للشمس والقمر ودوائر انحطاط الشفق (-16° و -18°).

2. **📅 شريط التنقل بين أيام السنة الفلكية (Annual Days Timeline):**
   - سلايدر انسيابي متصل للتنقل عبر كافة أيام السنة (1 إلى 365/366 يوماً) بدقة كسرية.
   - عرض فوري للتاريخ باليوم والشهر واسم البرج الفلكي والمحطة الموسمية.
   - أزرار قفز مباشر للمحطات الكبرى الأربع: 🌸 الاعتدال الربيعي، ☀️ الانقلاب الصيفي، 🍂 الاعتدال الخريفي، ❄️ الانقلاب الشتوي، و 🔴 اليوم الحالي.
   - أزرار التنقل السريع بين شهور السنة الـ 12.

3. **⏱️ محاكي تدفق الزمن (Time Simulation Engine):**
   - **🔴 1. واقعي:** يربط حركة الشمس والوقت بالتوقيت الفعلي الدقيق للمدينة المختارة (1 ثانية = 1 ثانية).
   - **⏱️ 2. السرعة بالساعات:** تسريع تدفق اليوم والليل (1 ثانية = 1 ساعة).
   - **📅 3. السرعة بالأيام:** متابعة تغير الفصول ومنازل القمر سريعاً (1 ثانية = 1 يوم).
   - **🌕 4. السرعة بالشهور:** دوران سنوي سريع للمدارات وحركة البروج (1 ثانية = 1 شهر).

4. **🕌 مواقيت الصلاة والربع المجيب (Astronomical Prayer Engine):**
   - حساب فلكي دقيق لمواقيت: الفجر، الشروق، الظهر، العصر (الشافعي والحنفي)، المغرب، والعشاءين (16° للشافعي vs 18° للحنفي).
   - توضيح أثر انحدار مسار الشمس صيفاً وشتاءً على اتساع الفارق بين العشاءين.
   - جدول مقارنة فصلي متكامل وعريض لكافة المحطات المدارية.
   - زر `🌅 الغروب` للقفز التلقائي للحظة غروب الشمس ورؤية هبوطها في الشفق.

5. **📍 تغطية جغرافية عالمية (+465 مدينة):**
   - دعم كامل لـ 465 مدينة إسلامية وعالمية ومراصد تاريخية شهيرة.
   - خريطة تفاعلية للبحث عن أي مدينة حول العالم وتوجيه القبة إليها فوراً.
   - ميزة تحديد الموقع التلقائي عبر الأقمار الصناعية `📍 موقعي (GPS)`.
   - دعم إدخال إحداثيات مخصصة (خط العرض وخط الطول).

6. **📱 جاهز للأجهزة الذكية (PWA & Mobile Ready):**
   - تصميم متجاوب متكامل يعمل على الهواتف والأجهزة اللوحية والحواسيب.
   - ملف `manifest.json` وأيقونات مدمجة لإمكانية التثبيت الفوري كتطبيق هاتف مستقل (Installable PWA).

## 🚀 التشغيل المباشر / Quick Start

### 1. التشغيل المحلي (Offline / Local):
لا حاجة لتثبيت أي برامج أو خوادم! فقط افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Safari, Edge):
```bash
# أو باستخدام أي خادم محلي سريع (اختياري):
npx serve .
# أو
python -m http.server 8080
```

### 2. النشر على GitHub Pages (Live Web Demo):
1. ارفع هذا المستودع إلى حسابك على GitHub.
2. من صفحة المستودع: اذهب إلى **Settings** ⬅️ **Pages**.
3. تحت **Branch**: اختر `main` واضغط **Save**.
4. خلال دقيقة واحدة سيصبح موقعك متاحاً برابط عالمي مجاني:
   `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`

## 📲 التحويل إلى تطبيق جوال (Android / iOS App)

بفضل معمارية هذا المشروع (Single Page App مع PWA Manifest)، يمكنك تحويله إلى تطبيق أندرويد (APK) أو iOS عبر **Capacitor**:

```bash
# تثبيت Capacitor
npm install @capacitor/core @capacitor/cli @capacitor/android

# تهيئة التطبيق
npx cap init "Ibn al-Shatir 3D" "com.ibnshatir.cosmos3d" --web-dir "."

# إضافة منصة أندرويد
npx cap add android

# مزامنة الملفات وفتح المشروع في Android Studio
npx cap sync
npx cap open android
```
